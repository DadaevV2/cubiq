# 🧊 CubIQ — «Волшебные кубы»

**Тактильная головоломка для детей и взрослых**  
Объединяет физические кубики с цифровым интеллектом. 8 цветных кубов, сенсорное управление, голосовые подсказки, сказки, ноты и логические игры.

🔗 **Живой сайт:** [https://cub-iq.ru](https://DadaevV2.github.io/cubiq)

---

## ✨ Особенности

- 🎲 **8 цветных кубов** — красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый
- 🔊 **Голосовая обратная связь** — куб говорит, показывает и подсказывает
- 📖 **4 сказки по 7 глав** — «Колобок», «Маша и Медведи», «Репка», «Теремок»
- 🎵 **7 нот** — изучайте музыку через игру
- 🎨 **Режим «Цвета»** — учим названия цветов на русском и английском
- 🧠 **Логические схемы** — И, ИЛИ, НЕ и сложные комбинации
- 📱 **PWA-приложение** — работает офлайн, устанавливается на телефон
- 🛠️ **Конструктор заказа** — соберите свой уникальный набор
