⚙️ Технические детали

🔩 Аппаратное обеспечение

  • Центральный куб: ESP 32 S
  • 5× RFID-модуль RC522
  • Мультиплексор CD74HC4067 (для экономии пинов)
  • MP3-плеер DFPlayer Mini + динамик 3W
  • Цветные кубы с RFID-метками (13.56 MHz)
  • Активационный куб (отдельная метка)
  • Питание: 5V 2A MicroUSB + стабилизатор 3.3V

💾 Программное обеспечение

  • Прошивка на C++ (Arduino IDE)
  • Библиотеки: MFRC522, DFPlayer_Mini_Mp3, CD74HC4067
  • Алгоритм: сканирование граней по очереди, проверка правил, воспроизведение MP3
  • PWA-приложение на HTML/CSS/JS (этот сайт)
  • Исходный код: GitHub

📦 Сборка набора

Подробная инструкция: PDF-руководство. Основные шаги:

  1. Спаять мультиплексор с RC522
  2. Подключить DFPlayer к Arduino
  3. Загрузить прошивку
  4. Вклеить RFID-метки в кубики
  5. Собрать корпус куба
